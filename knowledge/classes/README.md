# Catatan per Kelas Vuln
Satu file per kelas berisi: prasyarat bukti, jebakan false positive khas kelas itu, dan checklist negatif (yang harus sudah dites sebelum kelas dinyatakan "bersih" di sebuah target — anti premature-closure, doc 11).
Tersedia: `xss.md`, `idor-access-control.md`, `ssrf.md`, `sqli.md`, `auth-jwt.md`. Berikutnya: `cors.md`, `exposure-misconfig.md`, `open-redirect.md`.
Ringkasan jebakan terpenting sudah tertanam di SKILL.md tiap skill terkait; folder ini adalah rumah versi lengkapnya.
